Sistema integral desarrollado con el Framework de Agregación de MongoDB, una API REST construida en Node.js v24 LTS con protección JWT, y un Dashboard analítico interactivo con la paleta de diseño Jade Pebble Morning.

Materia: Big Data Prof: M.A.V.D. José Jesús Sánchez Farías
